2000STARS — site Y2K para TCC

COMO ABRIR:
1. Extraia a pasta 2000stars.
2. Abra a pasta no VS Code com "Open Folder".
3. Abra o arquivo index.html no navegador.
4. Para facilitar, você pode instalar a extensão "Live Server" no VS Code e clicar com o botão direito em index.html > Open with Live Server.

ESTRUTURA:
index.html       página inicial
moda.html        página de moda
beleza.html      página de beleza
tendencias.html  página de tendências
quiz.html        quiz interativo
sobre.html       página sobre o projeto
css/style.css    todo o visual
js/script.js     contador, guestbook e quiz
images/          pasta reservada para imagens futuras

OBSERVAÇÃO:
O contador e o guestbook usam localStorage, então funcionam no navegador sem banco de dados. Para um TCC que exija login, banco de dados ou comentários online, será necessário adicionar backend posteriormente.
