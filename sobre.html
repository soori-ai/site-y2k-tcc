★ ABOUT THIS SITE ★

SOBRE O 2000STARS

Um pedacinho da internet antiga, recriado para hoje.

QUAL É A IDEIA?

O 2000Stars é um blog fictício dedicado à moda, beleza e tendências inspiradas na estética Y2K. O projeto busca reproduzir elementos visuais marcantes da web dos anos 2000, como barras laterais, botões, cores vibrantes, pequenos banners, contador de visitantes e estética de diário pessoal.

TECNOLOGIAS

HTML
estrutura
CSS
design
JS
interação

O site foi estruturado com HTML, estilizado com CSS e recebeu recursos interativos em JavaScript, como o quiz, contador de visitantes e guestbook.

POR QUE Y2K?

A estética foi escolhida por sua identidade visual forte e por permitir explorar criatividade, design e nostalgia digital. O objetivo não é reproduzir uma página específica, mas reinterpretar a linguagem visual da internet daquela época em um projeto próprio.
